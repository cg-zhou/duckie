# 原有工具箱模式

PAC、音量、快捷启动、设置、关于、快捷键及托盘代码均保留。首发模式只限制加载入口，不删除旧功能和用户配置。

退出当前实例后，运行 `Duckie.exe --toolbox`，恢复原有导航发现、托盘、快捷键注册、应用 HTTP 代理、启动最小化和关闭时收起行为。两种模式共用单实例锁，切换前应先退出。

| 默认快捷键 | 操作 |
| --- | --- |
| Alt + Shift + E | 显示或隐藏窗口 |
| Alt + Shift + 1 | 循环切换 PAC，最后清空 |
| Alt + Shift + 8 / 9 / 0 | 音量减 / 加 / 静音 |
| Alt + Shift + 5 | 切换右键菜单并重启资源管理器 |

快捷键可在原有页面修改；快捷启动保留 Application 2 文件绑定。PAC 修改当前用户的 Windows 自动配置地址，不提供代理服务。设置中的 HTTP 代理仅用于 Duckie 自身请求。

全局快捷键仍可能与其他应用冲突。单实例处理避免 Duckie 重复启动造成的重复注册，不会解除其他程序对按键的占用。
