# Duckie v0.9.1

首个可下载的右键菜单切换版本，修正了 v0.9.0 的自动发布附件路径。

- Windows 11 经典 / 默认右键菜单图片对比，点击选择样式。
- 切换前确认；重启资源管理器后生效，可恢复系统默认。
- 无需安装，单实例运行，关闭窗口即退出。
- 默认不注册全局快捷键、不创建托盘图标。
- 原有工具箱和已调试代码保留，退出后可通过 `--toolbox` 参数启用。

下载 `Duckie-v0.9.1.exe` 后直接运行。需要 Windows 11 和 .NET Framework 4.8。`SHA256SUMS.txt` 提供校验值，`release.json` 为网站同步提供元数据。

菜单效果取决于 Windows 版本。切换会重启资源管理器，建议先结束文件操作。便携版未进行代码签名，Windows 可能显示未知发布者提示；请从本站或项目 GitHub Releases 下载。
