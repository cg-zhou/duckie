# Duckie v0.9.0

首个聚焦 Windows 11 右键菜单切换的便携版本。

- 通过图片选择经典菜单或 Windows 11 默认菜单。
- 切换前确认，操作会重启资源管理器；可随时恢复系统默认。
- 单实例运行，重复打开会唤起已有窗口。
- 无需安装，关闭窗口即退出；不注册全局快捷键、不创建托盘图标。
- PAC、音量和快捷启动等旧功能暂不启用。

## 下载与运行

下载 `Duckie-v0.9.0.exe`，在 Windows 11 上直接运行。需要 .NET Framework 4.8，通常已随系统提供。

`SHA256SUMS.txt` 提供文件校验值，`release.json` 提供网站同步使用的版本元数据。

菜单效果取决于 Windows 版本。程序显示的是当前用户的配置，不保证所有未来系统版本都支持同样的菜单效果。切换会重启资源管理器，建议先结束正在进行的文件操作。

本版本未进行代码签名，Windows 可能显示未知发布者提示。仅从项目发布页或 `duckie.cg-zhou.top` 下载，遇到问题可提交 Issue。
