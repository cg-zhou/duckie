简单三步

换个菜单，不用折腾。

不用找教程，不用自己修改注册表。

  1. 1

    下载，打开

    一个 EXE 文件。打开就是菜单选择页，没有安装向导。

  2. 2

    选你习惯的样式

    点击菜单图片，确认后切换。当前配置会用边框标记。

    继续手头的事

    资源管理器重启后查看效果。关闭 Duckie 即退出，不在托盘常驻。

ⓘ 切换会重启资源管理器，任务栏和桌面会短暂消失。建议先结束正在进行的文件操作。

打开之前

你可能想知道。

支持哪些系统？

面向 Windows 11，需要 .NET Framework 4.8。具体菜单效果取决于 Windows 版本，程序中的选中状态表示当前配置。

能改回 Windows 11 默认菜单吗？

可以。重新打开 Duckie，选择 Windows 11 菜单并确认，即可移除经典菜单配置、恢复系统默认。

关闭后还会在后台运行吗？

首发模式关闭窗口即退出，不注册全局快捷键，不创建托盘图标。

为什么 Windows 提示未知发布者？

当前便携版未进行代码签名。请从本站或 GitHub Releases 下载；可以通过下面的 SHA-256 校验值核对文件。
